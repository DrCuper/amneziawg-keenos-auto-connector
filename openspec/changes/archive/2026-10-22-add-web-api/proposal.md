# Proposal

## Why

После этапов 1–4 сервис управляется только из CLI на той же машине: чтобы
посмотреть журнал, добавить домен в группу, откатить версию или проверить
туннель, нужно зайти по SSH. Для повседневного использования (с телефона, из
домашней сети) и для мониторинга нужен HTTP‑доступ. Это этап 5 плана из
`openspec/project.md`.

## What Changes

- **REST API** (`http-api`) в `awgkeen serve` по адресу `api.listen`:
  группы, их версии и записи; ручные правки, откат и открепление (с
  немедленным применением по флагу); синхронизация с dry‑run; журнал с
  фильтрами; активные алерты и результаты проверок; состояние роутера без
  ключей; AWG‑туннели — список, состояние, план и импорт; `/metrics` в формате
  Prometheus. JSON, ошибки — `{"error": "..."}`.
- **Авторизация**: Bearer‑токены — полный (`api.token`) и только чтение
  (`api.read_token`), из env `AWGKEEN_API_TOKEN`/`AWGKEEN_API_READ_TOKEN`,
  файлов или YAML. Без токена API разрешено только на loopback‑адресе.
  Опционально HTTPS (`tls_cert_file`/`tls_key_file`).
- **Согласованность**: изменяющие операции API, расписание cron и импорт
  туннелей при старте выполняются по одной; занятый сервис отвечает 409.
  Операции из API пишутся в журнал с источником `api`.
- **Веб‑интерфейс** (`web-ui`): одна встроенная в бинарник страница на `/`
  (обзор, группы с версиями и ручными записями, журнал, туннели, роутер),
  работающая через тот же API; токен хранится в браузере. Данные выводятся
  только как текст, заголовки CSP/X‑Frame‑Options/nosniff.

Вне scope: пользователи и роли сверх двух токенов, OAuth, WebSocket‑обновления,
управление сервером AWG (этап 6), редактирование `domains.yaml` через API.

## Capabilities

### New Capabilities
- `http-api`: REST API и метрики демона.
- `web-ui`: встроенный веб‑интерфейс.

### Modified Capabilities
(нет — API вызывает существующие операции; `syncer` получает `DefaultTrigger`
и `TriggerAPI`, `health.Monitor` — колбэк результатов)

## Impact

- Новый пакет `internal/api` (обработчики, авторизация, метрики, встроенная
  страница `web/index.html`).
- `internal/app.NewAPI`, `cmd/awgkeen serve`: HTTP‑сервер с graceful shutdown,
  общий мьютекс операций, последние результаты проверок.
- `internal/journal.ParseSince` вынесен из CLI для фильтра `since`.
- Конфиг: секция `api`. Новых зависимостей нет (stdlib `net/http`, шаблоны
  маршрутов Go 1.22+).
