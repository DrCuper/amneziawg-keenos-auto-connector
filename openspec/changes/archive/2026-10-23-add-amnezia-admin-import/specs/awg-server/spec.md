# Spec Delta

## ADDED Requirements

### Requirement: Сервер Amnezia по ключу администратора
Импорт ключа администратора AmneziaVPN SHALL регистрировать сервер с его
SSH‑доступом в `state_dir` (0600) с запоминанием host key при первом
подключении и SHALL читать из контейнера `amnezia-awg` ключи, адрес, порт и
параметры обфускации. Выдача и отзыв клиентов SHALL работать как для своего
сервера; роутер SHALL NOT меняться.

#### Scenario: Импорт ключа администратора
- **WHEN** оператор выполняет `awg import am vpn://…` с ключом полного доступа
- **THEN** сервер `am` появляется в `server list`, `peer add -s am phone` выдаёт рабочий конфиг

#### Scenario: Подмена host key
- **WHEN** при следующем подключении host key сервера другой
- **THEN** подключение отклоняется

### Requirement: Сосуществование с приложением Amnezia
На сервере Amnezia система SHALL менять только своих клиентов, помеченные
`# awgkeen: <имя>`; `[Interface]` и клиенты приложения SHALL сохраняться, их
адреса SHALL NOT выдаваться повторно. Применение SHALL идти без перезапуска
интерфейса. При смене ключей сервера деплой SHALL останавливаться с ошибкой.

#### Scenario: Клиенты приложения
- **WHEN** в конфиге есть клиент приложения с `10.8.1.1/32` и выполнен `peer add phone`
- **THEN** `phone` получает `10.8.1.2/32`, клиент приложения остаётся без изменений

#### Scenario: Сервер переустановлен в приложении
- **WHEN** ключ сервера в контейнере отличается от прочитанного
- **THEN** деплой отказывает и предлагает `server init --force`
